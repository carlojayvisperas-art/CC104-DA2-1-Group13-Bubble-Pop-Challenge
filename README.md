
# Pop the Bubble
### CC104 - Data Structures and Algorithms Project

## Project Description
Pop the Bubble is a simple browser-based game where players click growing bubbles to earn points before the bubbles reach their maximum size.

## Game Features
- Random bubble generation
- Unique bubble IDs
- Growing bubbles
- Click bubbles to pop them
- Score tracking
- Three lives
- Automatic bubble bursting
- Game over system
- Restart button

## Data Structures and Algorithms
**Data Structure:**
- Array of Objects

**Operations and Algorithms:**
- Insertion using `push()`
- Traversal using `for` loops
- Searching using `find()`
- Filtering and removal using `filter()`

## Technologies Used
- HTML
- CSS
- JavaScript
- jQuery

## How to Play
1. Open `index.html` in your browser.
2. Click Start Game.
3. Click the bubbles to earn points.
4. Avoid letting bubbles reach their maximum size.
5. You lose one life for every bubble that bursts.
6. The game ends when all three lives are lost.
7. Click Restart to play again.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
